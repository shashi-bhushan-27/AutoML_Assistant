*** DOMAIN: TABULAR MACHINE LEARNING (models this app can train) ***
Supported models: XGBoost, Random Forest, Extra Trees, Gradient Boosting, Hist Gradient Boosting, AdaBoost, Decision Tree, SVM, KNN, Logistic Regression (classification), Linear Regression, Ridge, Lasso, ElasticNet (regression). Time series only: Prophet, ARIMA, SARIMAX.

[RULE: CLASSIFICATION_TASK]
IF the target is categorical (labels such as yes/no, fraud/normal, low/medium/high):
    THEN the task is classification.
    RECOMMENDED: XGBoost, Random Forest, Hist Gradient Boosting, plus Logistic Regression as a simple baseline.

[RULE: REGRESSION_TASK]
IF the target is a continuous number (price, amount, temperature):
    THEN the task is regression.
    RECOMMENDED: XGBoost, Random Forest, Hist Gradient Boosting, plus Ridge or Linear Regression as a simple baseline.

[RULE: SMALL_DATASET]
IF the dataset has fewer than 1,000 rows:
    THEN prefer simple or strongly regularised models that overfit less.
    RECOMMENDED: Logistic Regression or Ridge / Lasso, Random Forest, KNN, SVM.
    NOTE: every model is cheap at this size; compare them with cross-validation.

[RULE: MEDIUM_DATASET]
IF the dataset has between 1,000 and 100,000 rows:
    THEN tree ensembles are usually the strongest choice.
    RECOMMENDED: XGBoost, Random Forest, Hist Gradient Boosting, Extra Trees.
    NOTE: SVM training time grows quadratically; it stays practical up to roughly 20,000 rows.

[RULE: LARGE_DATASET]
IF the dataset has more than 100,000 rows:
    THEN training and prediction cost matter.
    RECOMMENDED: Hist Gradient Boosting, XGBoost, Logistic Regression or Ridge.
    AVOID: SVM (quadratic training time), KNN (slow prediction), exact Gradient Boosting (slow on many rows).

[RULE: SEVERE_CLASS_IMBALANCE]
IF the task is classification AND the minority class is under 10% of the rows:
    THEN accuracy is misleading; judge models by F1, precision/recall or PR-AUC.
    RECOMMENDED: XGBoost, Hist Gradient Boosting, Random Forest, Logistic Regression, trained with balanced class weights.
    AVOID: exact Gradient Boosting on very large, very imbalanced data (unstable and slow).

[RULE: MANY_CATEGORICAL_FEATURES]
IF most features are categorical:
    THEN tree ensembles cope well with one-hot, target and frequency encoded columns.
    RECOMMENDED: XGBoost, Random Forest, Hist Gradient Boosting, Extra Trees.
    NOTE: linear models need one-hot encoding and can suffer from many sparse columns.

[RULE: ALL_NUMERIC_FEATURES]
IF all features are numeric and the dataset is small or medium:
    THEN distance and kernel methods are viable after scaling.
    RECOMMENDED: XGBoost, Random Forest, SVM, KNN.

[RULE: SKEWED_FEATURES_AND_OUTLIERS]
IF numeric features are strongly skewed or contain outliers:
    THEN tree-based models are robust because they split on thresholds.
    RECOMMENDED: Random Forest, XGBoost, Extra Trees, Hist Gradient Boosting.
    NOTE: Linear Regression, SVM and KNN are sensitive to extreme values.

[RULE: LINEAR_RELATIONSHIP]
IF features correlate strongly and linearly with the target:
    THEN linear models are competitive and easy to explain.
    RECOMMENDED: Ridge, Lasso, ElasticNet or Linear Regression (regression); Logistic Regression (classification).

[RULE: NONLINEAR_RELATIONSHIP]
IF the correlation between features and target is weak or nonlinear:
    THEN use models that learn interactions.
    RECOMMENDED: XGBoost, Random Forest, Extra Trees, Hist Gradient Boosting.

[RULE: MISSING_VALUES_PRESENT]
IF the dataset has missing values:
    THEN the app imputes them (median / most frequent value, fitted on training rows).
    RECOMMENDED: XGBoost, Hist Gradient Boosting and Random Forest are robust to imputed values.

[RULE: HIGH_DIMENSIONAL_DATA]
IF there are many features relative to the number of rows:
    THEN regularisation matters.
    RECOMMENDED: Lasso, ElasticNet, Logistic Regression, Random Forest.

[RULE: MULTICLASS_TARGET]
IF the target has more than two classes:
    THEN use models with native multi-class support.
    RECOMMENDED: Random Forest, XGBoost, Hist Gradient Boosting, Logistic Regression, KNN.

[RULE: INTERPRETABILITY_AND_EXPLANATIONS]
IF explanations are important:
    THEN tree and linear models give fast, exact SHAP explanations.
    RECOMMENDED: XGBoost, Random Forest, Decision Tree, Logistic Regression, Ridge.
    NOTE: SVM and KNN need the slow model-agnostic KernelExplainer.

[RULE: WEAK_LEARNERS]
AdaBoost and a single Decision Tree are usually weaker than Random Forest or XGBoost.
    USE them as interpretable baselines, not as the main candidates.

[RULE: TIME_SERIES_DATA]
IF rows are ordered by a date column and the target is numeric:
    THEN split chronologically (train on the past, test on the future).
    RECOMMENDED: Prophet, ARIMA, SARIMAX, or XGBoost / Random Forest with date features.
